READY OR NOT, GAMBLE! TOURNAMENT RULES

GENERAL TOURNAMENT RULES & ETIQUETTE

-
  • All controllers are permitted for use in the tournament, however keyboard is disallowed. If you do not have any sort of controller and are only able to use keyboard, you will be unable to participate.
  • Treat other competitors with respect. Malicious actions such as harassment or insulting are not to be tolerated and will immediately disqualify you from the tournament.

GENERAL GAME RULES

-
  • All matches will be played remotely via Parsec. If you are unable to use Parsec for any reason, you will be unable to participate.
    • If connection issues arise form the use of Parsec,
  • Pausing matches with the intention of disrupting your opponent's inputs is disallowed.
    • Pausing due to a controller disconnection, to change controls, or any similar matter will not result in any penalty.
  • Rule changes set by random conditions are required to be followed. Failure to do so will result in a forfeit of the match and be considered an automatic loss.
  • Before a match, players are allowed to set their controls, and if deisred, enter a match for a button check if the current game does not provide a suitable method of doing so outside of battle. Doing so does not have any specified time limit, however players are requested to be quick in doing so, and taking too long will be considered stalling at the T.O.'s discretion.
